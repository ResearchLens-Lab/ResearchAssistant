## Overview

ResearchLens `v0.1.0-alpha.1` is the first public alpha release of the ResearchLens desktop research workspace. It provides an offline-first, local-CPU research assistant that indexes academic and technical documents, extracts page-accurate text and sections, and generates provenance-grounded answers with verifiable citations without requiring external cloud LLMs, GPUs, or paid APIs.

---

## Key Capabilities

1. **Default Deterministic Research Engine**
   - Embedded SQLite database utilizing the FTS5 full-text search extension with WAL mode.
   - Lexical retrieval combining BM25 scoring with TF-IDF query expansion and reciprocal-rank fusion.
   - Deterministic answer composition assembling responses directly from retrieved passages.
   - Page-accurate citation markers (`[S1]`, `[S2]`) tied directly to source files, section headers, and page numbers.
   - Strict academic abstention when queried facts are absent from loaded documents.

2. **Desktop Application Experience**
   - Windows x64 NSIS installer providing a self-contained installation.
   - Built-in Next.js 15 frontend and FastAPI backend running on local loopback (`127.0.0.1`).
   - Research Library for managing projects and sources.
   - Interactive Research Desk with side-by-side Evidence Inspector.
   - Real-time diagnostic bar showing offline status and engine health.

3. **100% Offline & Private**
   - Operates with zero network calls in default configuration.
   - Verified by automated network isolation tests (`test_offline_strict.py`).
   - All documents, indexes, and session databases remain local to the user's machine.

4. **Open-Source & Compliant**
   - Licensed under AGPL-3.0 with complete source code available on GitHub.
   - Bundles complete third-party license notices (`THIRD_PARTY_NOTICES.md` and `THIRD_PARTY_LICENSES.md`).
   - Includes synthetic benchmark PDF fixture for testing out of the box.

## System Requirements

- **Operating System:** Windows 10 (64-bit) or Windows 11 (64-bit)
- **Processor:** Intel Core i3 / AMD Ryzen 3 or higher (x64 architecture)
- **RAM:** 4 GB minimum (8 GB recommended for large document collections)
- **Disk Space:** 500 MB free disk space for application files and local indexes

## Installation Instructions

1. Download `ResearchLens-Setup-0.1.0-alpha.1-x64.exe` and its verification checksum `ResearchLens-Setup-0.1.0-alpha.1-x64.exe.sha256`.
2. (Optional) Verify SHA-256 checksum in PowerShell:
   ```powershell
   Get-FileHash -Algorithm SHA256 .\ResearchLens-Setup-0.1.0-alpha.1-x64.exe
   ```
3. Run `ResearchLens-Setup-0.1.0-alpha.1-x64.exe` to install the desktop application.
4. Launch ResearchLens from the Start Menu or desktop shortcut.

---

## Known Limitations & Alpha Status

- This is an **alpha pre-release** (`0.1.0-alpha.1`) intended for early testing, architectural review, and community feedback.
- Packaged desktop installer is currently provided for Windows x64. Linux and macOS desktop builds are supported via source execution.
- Optional Ollama and cloud LLM integrations require user-managed local instances or API keys and are disabled by default.
