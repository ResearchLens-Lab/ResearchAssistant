## Overview

ResearchLens `v0.1.0-alpha.2` delivers **Deterministic Answer Generation V2**, a comprehensive overhaul of our local-first, model-free extractive research engine incorporating technical feedback from the research and RAG community. This release eliminates sentence truncation, enhances cross-document synthesis, introduces pure-Python graph-based TextRank ranking, prevents dangling reference fragmentation, and reinforces strict honest abstention while preserving zero-cloud, 100% offline local CPU execution.

---

## What's New in v0.1.0-alpha.2

### 1. Deterministic Answer Generation V2 Engine
- **Sentence-Level BM25 Scoring**: Exact lexical scoring evaluated at granular sentence boundaries instead of coarse paragraph chunks.
- **Maximal Marginal Relevance (MMR)**: Redundancy reduction balancing relevance against sentence diversity with configurable similarity penalties.
- **Pure-Python TextRank**: Graph-based extractive summarization using co-occurrence networks and power iteration with zero external dependencies.
- **Antecedent Context Restoration**: Automatic resolution of dangling demonstratives ("This paper...", "These findings...") by prepending defining antecedent sentences.
- **Evidence Sufficiency Validation**: Deterministic validation ensuring numerical values, units, and metrics cited in answers match source records.
- **Structured Procedural Extraction**: Automatic identification and formatting of sequential algorithmic and experimental steps.
- **Section-Aware Multi-Document Synthesis**: Hierarchical grouping of evidence by source document and section header.
- **Honest Abstention**: Complete abstention (`Evidence state: NOT FOUND`) when queried facts are ungrounded in selected documents.

### 2. Desktop Runtime Synchronization & Build Enhancements
- **Runtime Staging Sync**: Build pipeline (`desktop/scripts/build.mjs`) automatically synchronizes V2 modules (`rag/independent/sentence_selector.py`) into the packaged desktop runtime.
- **Integrity Tracking**: Manifest validation tracks module hashes across all core engine files.
- **Seamless Local Loopback**: Native desktop shell with loopback authentication and isolated SQLite library storage.

### 3. Verification & Quality Assurance
- **Full Backend & RAG Regression Suite**: 488 passed, 0 failed, 46 skipped (in 221.64s).
  - *Skipped Tests Census*: 45 tests explicitly marked for legacy vector/cloud providers superseded by the offline lexical engine; 1 test requires optional external export JSON.
- **Frontend Regression Suite**: 34 passed, 0 failed (in 430ms).
- **Expanded Real-World Benchmark**: 16 evaluation cases achieving 100% determinism, 100% factual grounding, 100% citation accuracy, 100% abstention accuracy, and sub-50ms warm latency.
- **Desktop Workflow Validation**: 10/10 representative desktop workflows verified on real academic PDFs.
- **Strict Offline Guarantee**: 100% verified with zero network calls, zero external APIs, zero telemetry, and zero neural embedding calls.

## Installation Instructions

1. Download `ResearchLens-Setup-0.1.0-alpha.2-x64.exe` and its verification checksum `ResearchLens-Setup-0.1.0-alpha.2-x64.exe.sha256`.

   ```powershell

   ```
3. Run `ResearchLens-Setup-0.1.0-alpha.2-x64.exe` to install the desktop application.
4. Launch ResearchLens from the Start Menu or desktop shortcut.
