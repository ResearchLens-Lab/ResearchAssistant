What fundamental computational limitation prevents Vaswani et al. (2017) attention from scaling beyond 512–1024 token sequences natively without sparse approximations?

lightbulb

Recall Clue: Focus on the matrix dimensionality allocation inside the softmax function and memory complexity $O(n^2)$.

Click card or button to rotate 180°
verified Verified Grounded Answer
cite p.4 §3.2.1
Quadratic Memory & Compute Footprint:

The computation of the attention weight matrix requires calculating Softmax(QK^T / \sqrt{d_k}). This generates an n × n inner-product matrix where memory allocation scales as O(n²).

Corpus Excerpt (Vaswani et al. 2017):
"A self-attention layer connects all positions with a constant number of sequentially executed operations... whereas computational complexity per layer is O(n² · d)."

Scaled Dot-Product Attention: Variance Normalization Proof

Eq. (1) Vaswani
1
Step 1: Inner Product Variance Expansion
Assume $q_i, k_i \sim \mathcal{N}(0, 1)$ are independent random variables.
expand_more
$\text{Var}(q \cdot k) = \sum_{i=1}^{d_k} \text{Var}(q_i k_i) = \sum_{i=1}^{d_k} \mathbb{E}[q_i^2]\mathbb{E}[k_i^2] = d_k \times (1 \times 1) = d_k$

For large values of $d_k$, the dot products grow large in magnitude, pushing the softmax function into regions with extremely small gradients.

2
Step 2: Division by $\sqrt{d_k}$ Scaling Factor
Rescaling scalar coefficient application to normalize variance to 1.
expand_more
$\text{Var}\left(\frac{q \cdot k}{\sqrt{d_k}}\right) = \frac{1}{(\sqrt{d_k})^2} \text{Var}(q \cdot k) = \frac{1}{d_k} \cdot d_k = 1.0$

By counteracting the variance expansion through $\frac{1}{\sqrt{d_k}}$, the pre-softmax activations maintain unit variance independent of hidden embedding width.

3
Step 3: Gradient Vanishing Mitigation in Softmax
Preventing saturation in the exponential multinomial distribution.
expand_more
$\frac{\partial \text{Softmax}(z)_i}{\partial z_j} = \text{Softmax}(z)_i (\delta_{ij} - \text{Softmax}(z)_j) \approx 0 \quad \text{when } |z_i| \gg 0$

Ensures backpropagated gradients $\frac{\partial \mathcal{L}}{\partial Q}$ and $\frac{\partial \mathcal{L}}{\partial K}$ do not underflow during FP16 mixed-precision training.
