Vaswani, Shazeer, Parmar, Uszkoreit, Jones, Gomez, Kaiser, Polosukhin

3.2 Attention

An attention function can be described as mapping a query and a set of key-value pairs to an output, where the query, keys, values, and output are all vectors. The output is computed as a weighted sum of the values, where the weight assigned to each value is computed by a compatibility function of the query with the corresponding key.

3.2.1 Scaled Dot-Product Attention

We call our particular attention "Scaled Dot-Product Attention" (Figure 2). The input consists of queries and keys of dimension d_k, and values of dimension d_v. We compute the dot products of the query with all keys, divide each by √d_k, and apply a softmax function to obtain the weights on the values.

Figure 2: (left) Scaled Dot-Product Attention.

In practice, we compute the attention function on a set of queries simultaneously, packed together into a matrix Q. The keys and values are also packed together into matrices K and V.

"We compute the attention function on a set of queries simultaneously, packed together into a matrix Q. We compute the matrix of outputs as:

Attention(Q, K, V) = softmax( Q KT / √dk ) V
(1)

The two most commonly used attention functions are additive attention, and dot-product (multiplicative) attention. Dot-product attention is identical to our algorithm, except for the scale factor of 1 / √dk. To counteract this effect, we scale the dot products by 1 / √dk."

While for small values of d_k the two mechanisms behave similarly, additive attention outperforms dot product attention without scaling for larger values of d_k. We suspect that for large values of d_k, the dot products grow large in magnitude, pushing the softmax function into regions where it has extremely small gradients.

Footnote 4 Lemma

The paper justifies the scaling constant 1 / √d_k by tracking variance growth under independent zero-mean unit-variance components:

1. Given: q_i, k_i ~ i.i.d., E[q_i] = E[k_i] = 0, Var(q_i) = Var(k_i) = 1
2. Expectation: E[q · k] = ∑_{i=1}^{d_k} E[q_i k_i] = ∑ 0 = 0
3. Variance Expansion: Var(q · k) = ∑_{i=1}^{d_k} Var(q_i k_i) = ∑ 1 = d_k
4. Scaled Dot Invariance: Var( (q · k) / √d_k ) = (1 / d_k) · d_k = 1.0 (Unit Variance Restored)
