Scaled Dot-Product Attention

Architecture Hub §3.2.1 Vaswani et al.
Mathematical Formulation Eq. 1 • Attention Matrix
Attention(Q, K, V) = softmax(Q KT√dk) V

Stabilizes variance growth across high-dimensional projection tensors. For large values of d_k, the dot products grow large in magnitude, pushing the softmax function into regions with extremely small gradients. Dividing by √d_k counteracts this expansion.
