# Topic Coverage Analysis Specification
**System:** ResearchLens Independent Research Engine  
**Module:** `rag/independent/topic_analyzer.py`  
**Execution Context:** 100% Deterministic, Local, Model-Free Curriculum Analysis  

---

## 1. Overview and Design Objectives

In academic syllabi, course guides, and technical curriculum standards, sections are rarely uniform in structure. Evaluating which section possesses *"more syllabus or topics"* cannot be answered by raw token counts or unparsed character lengths, because descriptive prose (e.g. detailed notes on one concept) can easily exceed dense enumerations of multiple distinct subjects.

The `TopicCoverageAnalyzer` was designed to parse and evaluate curriculum structures deterministically using a two-level hierarchical model:
1. **Level 1 — Main Topic Groups (Subject Disciplines)**: Explicit major disciplines within a section (e.g. Section 1 contains *Discrete Mathematics*, *Linear Algebra*, *Calculus*, *Probability and Statistics*).
2. **Level 2 — Individual Subtopics**: Specific concepts, algorithms, theorems, or data structures enumerated within each group (e.g., *Propositional and first order logic*, *Eigenvalues and eigenvectors*).

---

## 2. Topic Extraction Algorithm

### 2.1 Main Subject Group Detection
Major subject divisions within a section are identified using regex lookbehinds and colon delimiters:
```python
COLON_HEADER_PATTERN = re.compile(
    r"(?:^|(?<=[.!?\n]\s))([A-Z][A-Za-z\s/&–-]{2,40}):\s*"
)
```
When matches are detected:
- The matched phrase becomes a `main_group` (e.g. `"Discrete Mathematics"`, `"Linear Algebra"`).
- The text following the colon until the next header is isolated as the scope for that group's subtopics.

### 2.2 Subtopic Slicing and Normalization
Within each group's text block:
1. Semicolons (`;`) are treated as primary subtopic delimiters.
2. Commas (`,`) separating distinct technical phrases ($\ge 4$ characters) are extracted as secondary subtopics.
3. Stopwords, formatting artifacts, and institutional markers (`GATE 2027`, `IIT Madras`, `Organizing Institute`) are stripped.
4. If no colon headers are present in a section (e.g. Section 2: Digital Logic), the section itself constitutes 1 main group, and its subtopics are extracted directly from sentence-level semicolon/comma boundaries.

## 3. Data Contract & Schema Specifications

The module defines two Pydantic models in `rag/independent/topic_analyzer.py`:

```python
class SectionTopicProfile(BaseModel):
    section_name: str
    main_group_count: int
    main_groups: list[str]
    subtopics_count: int
    subtopics: list[str]
    supporting_passage: str
    page_start: int
    page_end: int
    source_id: str
    chunk_id: str
    paper_id: str
    document_id: str

class CurriculumAnalysisResult(BaseModel):
    top_section: SectionTopicProfile
    ranked_sections: list[SectionTopicProfile]
    is_tie: bool
    counting_methodology: str
    structural_notes: str
```

## 4. Ranking and Tie-Breaking Logic

To evaluate which section has the greatest curriculum breadth:

1. **Primary Sort Key**: `main_group_count` (Descending)  
   A section encompassing 6 major university disciplines (like Section 1) has fundamentally greater scope than a section containing 1 discipline.
2. **Secondary Sort Key**: `subtopics_count` (Descending)  
   Breaks ties between sections having the same number of main groups by total enumerated subtopics.
3. **Tertiary Sort Key**: Physical appearance order (`page_start`, `chunk_id`).

### Support for Reverse Inquiries ("Fewest Topics / Least Syllabus")
When users ask for the section with the *"fewest topics"* or *"least syllabus"*, the analyzer reverses the primary and secondary sort orders (`main_group_count ASC, subtopics_count ASC`), correctly identifying single-topic units like Section 4 (Programming and Data Structures) or Section 2 (Digital Logic).
