# Code of Conduct

## Standards

Contributors and maintainers of ResearchLens are expected to maintain professional and collaborative standards:

- Provide constructive technical feedback focused on code quality and reproducibility.
- Maintain respectful collaboration across all project discussions, issue threads, and pull requests.
- Uphold research integrity, accurate documentation, and transparent citations in all contributions.

## Unacceptable Behavior

The following behaviors are prohibited:

- Personal attacks, harassment, or derogatory comments.
- Trolling, inflammatory remarks, or disruptive conduct.
- Publishing private information of others without explicit consent.

## Inquiries

Project maintainers oversee community standards. Concerns may be directed to the project lead at `goravgumber@gmail.com`.
